# Roadmap

## Shipped in 1.0.0

- Standalone researcher-to-mentor Agent Skill with identity/census, paper/code/reproduction evidence stages
- Method-to-code and claim-to-experiment protocols; skeptic reviewer + minimal pilot rules
- Offline workspace creation, candidate bibliography CSV ingestion, deduplication and status dashboard
- Conditional adapter router for separately installed research skill packs
- Synthetic examples, MIT license, attribution, Chinese/English docs and CI

## Candidate future work (not implemented)

- User-authorized scholarly API integrations (OpenAlex/DBLP/Crossref), ORCID-aware dedupe and bibliographic snapshots
- PDF page inventory with figure/table anchors (never labeling it as full reading)
- Read-only repository AST browser with source maps and commit pinning
- GitHub issue-based research mentor project dashboard and plug-in adapters
- Researcher methodology coverage benchmark against human-reviewed reference notes

None of these features should be advertised as working before implemented and tested.
